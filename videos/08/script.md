# ۱ · پیش‌درآمد · ۰:۰۰ تا ۱:۳۰
🎬 لوح گلی، نور شمع، خط میخی. بعد کات به بازار کرمان در ظهر تابستان، هوا می‌لرزد.
```
[whispers] هزار و هفتصد و هشتاد سال پیش از میلاد. شهر ترقا، کنار فرات.

[serious] فرماندار شهر، برای پادشاهش نامه می‌نویسد. شکایتش عجیبه: «یخ آب می‌شه.»

[mysterious] یخ. توی بیابون. چهار هزار سال پیش.

[calm] پادشاه، زیمری‌لیم، روی یه لوح گلی نوشته که یه خونه‌ی یخ ساخته، «که پیش از این هیچ پادشاهی نساخته بود».

[serious] این لوح، الان توی موزه‌ی لوور نگه‌داری می‌شه.

[calm] حالا بیا بریم یه جای دیگه. کرمان. تیر ماه. گرما بالای چهل و پنج درجه.

[curious] اینجا، آدم‌ها هزار سال بود که وسط تابستون، شربت یخ می‌خوردن. بدون برق. بدون یخچال. بدون هیچ ماشینی.

[mysterious] یخ از کجا می‌اومد؟
```

# ۲ · لوح ترقا · ۱:۳۰ تا ۴:۰۰
🎬 نقشه‌ی فرات، ماری و ترقا. نمای لوح AO 20161 (عکس واقعی با مجوز آزاد). فرماندار با نامه.
```
[calm] اول برگردیم به همون لوح.

[calm] ماری، یه شهر قدرتمند کنار فرات بود. شاهش، زیمری‌لیم، آدم ثروتمند و پرحرفی بود. خودش و درباریانش هزاران لوح نامه به‌جا گذاشتن.

[serious] توی یکی از این لوح‌ها، زیمری‌لیم می‌گه توی شهر ترقا یه یخچال بنا کرده. یعنی ساختمونی برای نگه‌داشتن یخ.

[curious] ولی یخ از کجا می‌اومد؟ از کوه‌های شمال. توی زمستون، بردن‌ش پایین و توی چاله‌های عمیق و سرپوشیده ذخیره می‌کردن.

[serious] و بعد، یه نامه‌ی دیگه. فرمانداره. می‌گه نگه‌داشتن یخ سخته. آب می‌شه.

[calm] یعنی مشکل، چهار هزار سال پیش هم همین بود. فرق یخ و آب، فقط چند درجه‌ست.

[mysterious] ولی توی ایران، این مشکل یه جواب خیلی هوشمندانه‌تر پیدا کرد. جوابی که یه ساختمون عجیب و گنبدی‌شکل شد.
```

# ۳ · ساختمان عجیب · ۴:۰۰ تا ۷:۰۰
🎬 نمای هوایی یخچال میبد/کرمان در بیابان. گنبد مخروطی بلند، دیوار سایه، حوضچه‌ها. (عکس واقعی ویکی‌مدیا، یا بازسازی عکس‌سازی)
```
[calm] اگه توی ایران، کنار یه شهر کویری رد بشی، شاید یه ساختمون عجیب ببینی. گنبدی مخروطی، شبیه یه کلاه بلند گِلی.

[curious] اسمش «یخچال» ـه. یعنی جای یخ.

[calm] از بیرون، فقط یه گنبد بزرگه. ولی همه‌ی کار پشتشه.

[serious] اول، یه دیوار بلند گِلی. ارتفاعش از خود گنبد کمتر نیست. کارش یه چیزه: سایه. این دیوار، رو به شرق و غرب نمی‌ایسته. رو به جنوب می‌ایسته، که آفتاب کم‌ترین سایه‌ش رو بندازه.

[calm] جلوی دیوار، توی سایه، چند تا حوضچه‌ی کم‌عمق و دراز.

[serious] و بعد، خود گنبد. بخش اصلی‌ش، زیر زمینه. یه چاله‌ی بزرگ، گاهی ده‌ها متر عمق.

[mysterious] این‌ها همه، یه ماشین بودن. یه ماشین یخ‌سازی، بدون برق.
```

# ۴ · چطور یخ می‌ساختند · ۷:۰۰ تا ۱۰:۳۰
🎬 انیمیشن کدی: مقطع یخچال، شب سرد کویر، تابش به آسمان، یخ‌زدن آب. تایمر و دما.
```
[calm] بیا بریم سراغ فیزیک.

[calm] شب‌های کویر، اگه آسمون صاف باشه، فوق‌العاده سرده. چرا؟ چون زمین گرماش رو به آسمون پس می‌ده، و جلوش ابری نیست.

[serious] اینجا وارد می‌شه حوضچه. آب رو از قنات می‌گرفتن و شب، توی حوضچه‌ی کم‌عمق می‌ریختن. ⚠️

[curious] اون دیوار سایه هم کار می‌کرد. ظهر که آفتاب می‌زد، حوضچه‌ها زیر سایه بودن. نه گرم می‌شد، نه آب می‌شد.

[calm] نتیجه، توی زمستون ساده‌ست. صبح، یه لایه‌ی نازک یخ روی آب. جمعش می‌کردن.

[serious] ولی تو مرداد، توی کویر، این کار هم‌چنان جواب می‌داد؟ نه. یخ‌ها رو توی زمستون می‌ساختن و تا تابستون نگه می‌داشتن.

[curious] پس سؤال اصلی، یخ‌سازی نبود. نگه‌داری یخ بود.
```

# ۵ · نگه‌داشتن یخ · ۱۰:۳۰ تا ۱۴:۰۰
🎬 مقطع داخلی: گودال، لایه‌های یخ و کاه، سقف گنبدی، بادگیر، قنات. تصویر ساروج.
```
[calm] یخ‌ها رو می‌بردن توی گودال زیر گنبد. لای‌لای‌شون، کاه و حصیر می‌ریختن، تا بهم نچسبن و گرما بهشون نرسه.

[serious] دیوارها، با ملاتی به‌اسم «ساروج» ساخته می‌شد. ترکیبی از خاک رس، ماسه، خاکستر، آهک، و گاهی مو. ضدآب و بسیار محکم.

[calm] گنبد هم ساده نبود. شکل مخروطی، هوای گرم رو بالا می‌برد و از سوراخ بالای گنبد بیرون می‌داد.

[curious] بعضی یخچال‌ها بادگیر هم داشتن. هوای خنک رو می‌گرفتن و می‌فرستادن پایین.

[calm] و گاهی، کانالی از قنات از زیر یخچال رد می‌شد. آبِ سرد، دیوارها رو خنک نگه می‌داشت.

[mysterious] همه‌ی این‌ها، یه هدف داشت: یخ، که یه تیکه‌ش هم آب نشه.

[calm] خلاصه‌ش این: ایرانی‌ها فهمیده بودن گرما از کجا میاد، و برای هر راهش یه مانع ساختن. آفتاب، دیوار. هوای گرم، گنبد. زمین گرم، گودال. رطوبت، ساروج.
```

# ۶ · اقتصاد یخ · ۱۴:۰۰ تا ۱۷:۰۰
🎬 بازار، فروشندهٔ یخ، شربت، فالوده، طبیب با بیمار تب‌دار.
```
[calm] یه سؤال: یخ برای چی لازم بود؟

[calm] جواب اول: خوراکی. شربت، آب‌یخ، و فالوده، که امروز هم توی شیراز و یزد معروفه.

[serious] جواب دوم: دارو. توی طب قدیم، یخ برای پایین‌آوردن تب و درمان بعضی بیماری‌ها استفاده می‌شد.

[calm] جواب سوم: ثروت. یخ، کالای لوکس بود. توی گرمای تابستون، یه تیکه‌ش خیلی می‌ارزید.

[curious] یخچال‌ها معمولاً ملک مردم یا حکومت بود. «یخچال‌دار» یه شغل بود. توی زمستون یخ می‌ساخت، توی تابستون می‌فروخت.

[calm] یعنی یه صنعت کامل. بدون کارخانه. بدون برق.
```

# ۷ · پایان، و یک سؤال · ۱۷:۰۰ تا ۲۰:۰۰
🎬 یخچال متروکه در غروب، باد، گنبد ترک‌خورده. کات به یخچال برقی امروز.
```
[calm] امروز اکثر یخچال‌ها خاموشن. گنبدها ترک خوردن. بعضی‌ها رو برای ساختن جاده خراب کردن.

[serious] یخچال برقی اومد، و دانشی که هزار سال کار کرده بود، آروم از یادها رفت.

[mysterious] ولی همین حالا، مهندس‌ها دارن دوباره سراغ همین ایده‌ها می‌رن. خنک‌کردن بدون برق. سایه، تبخیر، و جریان هوا.

[curious] پس یه سؤال برای تو:

[calm] چقدر از دانش پدران ما رو، فقط چون «قدیمی» بود، دور انداختیم؟

[whispers] بگو توی کامنت‌ها.
```
